The <img> tag embeds an image. The src attribute specifies the image path, alt provides alternative text, and responsive images use max-width: 100% in CSS.

Profile Image (SVG)

This is an SVG image rendered inline. SVG (Scalable Vector Graphics) is resolution-independent and ideal for logos, icons, and illustrations.

Audio Element

🎵

Audio Demo — HTML5 <audio> tag

The HTML5 <audio> element plays audio files. The controls attribute adds play/pause/volume controls. Supports MP3, OGG, WAV formats.

🎬

Video Element

🎬

Video Demo — HTML5 <video> tag

The <video> tag plays video files with controls. The poster attribute shows a thumbnail. Supports MP4, WebM, OGG formats.

📺

Responsive iFrame Container

16:9 aspect ratio maintained

Responsive iFrame using the padding-bottom trick (56.25% = 16:9). Works for YouTube, Google Maps, or any embedded content at any screen size.

Figure & Figcaption

The <figure> element wraps media content. <figcaption> provides a visible caption/description for the media, improving accessibility and semantics.
